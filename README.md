# 🚀 Android Base Template (Compose + Hilt + MVVM)

A reusable Android starter template with modern architecture.

## 🧱 Tech Stack
- Kotlin
- Jetpack Compose
- Hilt (DI)
- Room DB
- MVVM
- Version Catalog (libs.versions.toml)
- Type-safe Navigation

## 📁 Architecture

- data/
- domain/
- presentation/
- di/
- navigation/
- theme/

## ⚡ Features
- Clean architecture (lightweight)
- Repository pattern (interface + impl)
- StateFlow-based ViewModel
- Material3 theming
- Scalable folder structure

## 🚀 How to Use

1. Click **"Use this template"**
2. Clone repo
3. Change:
   - Package name
   - App name
4. Start building 🚀

## 🧠 Notes

- Designed for fast app bootstrapping
- Avoids over-engineering
- Easy to scale later
